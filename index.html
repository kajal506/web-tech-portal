Syllabus / Unit 1: Internet & Protocols

Unit 1: Internet & Web Protocols

Quantum School of Technology • Duration: 7 Hours

1 History of the Internet & World Wide Web (WWW)

The journey of interconnected computing originated with ARPANET (1969), funded by DARPA, pioneering packet-switching networks over traditional circuit-switched telephone lines.

Key Distinction: The Internet is the global physical infrastructure of hardware cables, routers, and servers. The World Wide Web (invented by Sir Tim Berners-Lee in 1989 at CERN) is an application service built on top of the Internet using HTTP and HTML.

2 Core Application Protocols: HTTP, SMTP, POP3, MIME, IMAP

Internet communications rely on specialized application layer protocols defined across TCP/IP stacks:

Protocol Port Primary Function Key Characteristic
HTTP / HTTPS 80 / 443 Web resource transfer Stateless request-response architecture
SMTP 25 / 587 Sending / pushing mail Server-to-server mail propagation
POP3 110 / 995 Retrieving mail locally Downloads and deletes from remote mailbox
IMAP 143 / 993 Syncing remote mail Keeps multi-device mail in continuous sync

MIME (Multipurpose Internet Mail Extensions): Extends standard ASCII mail formats to allow multimedia, audio, and attachments.

3 Domain Name Server (DNS) & Web Browsers

The DNS resolves human-readable domain names into machine IP addresses.

DNS Resolution WorkflowArchitecture
Browser Cache ──> OS Cache ──> Recursive Resolver ──> Root DNS ──> TLD Server (.in) ──> Authoritative DNS

Web Browsers: Client programs comprising rendering engines (Blink, WebKit, Gecko) and JavaScript engines (V8, SpiderMonkey) to parse and render documents.

4 Web Servers

A Web Server is hardware and software that accepts HTTP/HTTPS requests from clients and responds with static HTML/CSS files or dynamic application data.

Popular Servers: Apache HTTP Server (process/thread-per-connection), Nginx (asynchronous event-driven architecture), and Microsoft IIS.
Syllabus / Unit 2: Client-Side Technologies & XML

Unit 2: Client-Side Technologies & XML

Quantum School of Technology • Duration: 8 Hours

1 Structural HTML: Lists, Tables, Images, Forms, Frames

HTML delivers structured semantics for the web. Forms capture user inputs and transmit data payloads to server routes:

HTML Form StructureHTML5
<form action="/submit-student" method="POST">
  <label for="roll">Roll Number:</label>
  <input type="text" id="roll" name="student_roll" required />
  <button type="submit">Register Record</button>
</form>

2 DHTML with JavaScript & Cascading Style Sheets (CSS)

Dynamic HTML (DHTML) unites HTML, CSS, JavaScript, and the DOM. It enables inline layout mutations and animated events directly without reloading the page.

3 XML Document Type Definition (DTD) & XML Schemas

XML separates content from presentation. Schemas validate document structure:

  • DTD: Older SGML-derived validation syntax with limited data typing support.
  • XSD (XML Schema Definition): Native XML syntax supporting precise data types, namespaces, and validation rules.

4 XML Processors: DOM vs SAX

Two distinct APIs exist to parse and navigate XML documents:

Feature DOM (Document Object Model) SAX (Simple API for XML)
Model Type Tree-based (In-Memory) Event-driven (Streaming)
Memory Consumption High (loads full document) Extremely Low (line-by-line)
Navigation Bidirectional read/write Forward-only, read-only
Syllabus / Unit 3: Web Services & AJAX

Unit 3: Web Services & AJAX Architecture

Quantum School of Technology • Duration: 7 Hours

1 Web Services Architecture: SOAP, WSDL, UDDI

  • SOAP: XML envelope specification for protocol negotiation and RPC calls.
  • WSDL: Machine-readable XML definition detailing service ports, data types, and bindings.
  • UDDI: Central registry index enabling automated discovery of distributed enterprise services.

2 Developing and Deploying Web Services

Services are implemented via contract-first or code-first approaches, deployed onto application runtimes (Tomcat, GlassFish), and exposed over standardized URIs.

3 AJAX: Performance & Programming

AJAX allows web pages to update asynchronously by exchanging data with a web server in the background, avoiding full-page reloads:

Async Fetch PatternJavaScript ES6
async function fetchExamDetails(subjectCode) {
  try {
    const res = await fetch(`/api/syllabus?code=${subjectCode}`);
    const data = await res.json();
    console.log("Exam Data Loaded:", data);
  } catch (err) {
    console.error("Network Exception:", err);
  }
}

4 CORBA (Common Object Request Broker Architecture)

An enterprise distributed computing standard defined by OMG. The Object Request Broker (ORB) acts as the communication bus mediating requests between objects across different operating systems and languages.

Syllabus / Unit 4: Web 2.0 & Web 3.0

Unit 4: Web 2.0, Web 3.0 & Semantic Web

Quantum School of Technology • Duration: 7 Hours

1 Web 2.0: Interactive and Social Web

The transformation from static read-only pages to user-contributed social ecosystems (Wikis, Blogs, Social Networks). Powered by Ruby on Rails, RESTful Open APIs, and dynamic widgets.

2 Web 3.0: Semantic Web, Mashups & RDF

Web 3.0 structures web data so that intelligent search agents can deduce contextual meaning rather than just matching text strings. Built on RDF (Resource Description Framework) utilizing Subject-Predicate-Object triples.

3 Search Engines, Recommender Systems & Edge Computing

Modern information processing applies collaborative filtering models to personalize experiences, while Edge Computing pushes computations closer to the client rather than centralized servers.

4 Dark Mode in Web Development

Implemented through CSS Custom Properties and hardware queries, reducing eye strain and saving battery life on OLED displays:

Dark Mode ImplementationCSS Media Query
@media (prefers-color-scheme: dark) {
  :root {
    --bg: #090d16;
    --surface: #111827;
    --text-main: #f9fafb;
    --border: #1f2937;
  }
}
Syllabus / Unit 5: Web 4.0 & Emerging Tech

Unit 5: Web 4.0, DWeb & Next-Gen Tech

Quantum School of Technology • Duration: 7 Hours

1 Web 4.0: AI-Powered Web & Personalized Content

The symbiotic web connecting autonomous machine learning agents and humans, enabling adaptive UIs, natural language interfaces, and contextual content generation.

2 Decentralized Web (DWeb) & Blockchain Integration

Decentralized storage models (IPFS) and cryptographic ledgers (Ethereum, Solana) eliminate single points of failure, enabling tamper-proof identity systems and trustless protocols.

3 IoT, AR & VR (WebXR) in Web Development

Connecting physical sensors to web dashboards via WebSockets/MQTT, and rendering real-time spatial 3D scenes directly inside browsers using WebGL and the WebXR Device API.

4 Impact of 5G on Web Technologies

Millimeter-wave frequencies offer sub-millisecond latencies and gigabit throughput. This allows browsers to run real-time cloud gaming, remote edge-rendered 3D simulations, and compute-heavy web pipelines smoothly.
